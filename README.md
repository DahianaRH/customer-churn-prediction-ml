# customer-churn-prediction-ml

Este proyecto busca predecir la probabilidad de abandono de clientes en una empresa de telecomunicaciones utilizando técnicas de Machine Learning. El objetivo es identificar clientes en riesgo de churn para apoyar estrategias de retención.

Dataset: Telco Customer Churn
Fuente: Kaggle (https://www.kaggle.com/datasets/blastchar/telco-customer-churn?resource=download)
Tamaño: ~7000 registros, 21 variables

Estructura del repositorio:
data/ 
notebooks/
reports/
README.md

Ejecución del notebook: El desarrollo del proyecto se realiza en un entorno reproducible utilizando Google Colab. El notebook se encuentra alojado en este repositorio de GitHub y puede ejecutarse directamente desde el siguiente enlace (https://colab.research.google.com/github/DahianaRH/customer-churn-prediction-ml/blob/main/churn_problem_description.ipynb). Se recomienda ejecutar las celdas de manera secuencial para garantizar la correcta reproducción de los resultados del análisis exploratorio y la preparación de los datos.

Librerías usadas:
- pandas
- numpy
- seaborn
- matplotlib
- scikit-learn

Metodología:
1. Exploración y análisis del dataset
2. Limpieza y tratamiento de valores faltantes
3. Transformación de variables categóricas (encoding)
4. Preparación de variables (X, y)
5. Modelado de clasificación supervisada

Objetivo del proyecto: Construir un modelo de clasificación supervisada para predecir el abandono de servicios en clientes.
